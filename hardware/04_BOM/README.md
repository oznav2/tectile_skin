# רשימות חומרים לרובוט

שתי רשימות המקור מבוססות על RP1.3.4. מספרי החלקים הומרו ל־ROBOSKIN; מספרי יצרן נשמרו.

| תצורה | רשימת חומרים |
| --- | --- |
| 5DOF_MotionHead - בסיס הפרויקט | [BOM](ROBOSKIN_BOM_5DOF_MotionHead.xlsx) |
| 7DOF_MotionHead - חלופת מקור | [BOM](ROBOSKIN_BOM_7DOF_MotionHead.xlsx) |

בשתי הרשימות גיליון חומרים כולל וגיליון חומרי אריזה. הגיליון הכולל מפרט מכלולים, חלקי מבנה, חלקים תקניים, לוחות, צמות ורכיבים קנויים, לרבות מספר חלק, שם, כמות, מהדורה וחומר.

בחרו את ה־BOM של התצורה המתאימה וחפשו את המסמכים לפי מספר החלק. [מכניקה](../01_Mechanic/README.md), [מעגלים](../02_PCB/README.md), [צמות](../03_Harness/README.md).

תוספות העור מתועדות בנפרד ב[רשימת רכיבי העור](../../electronics/system_bom.csv) וב[דוגמת 88 נקודות החישה](../../electronics/example_88_site_bom.csv). הדוגמה היא תצורת בדיקה כללית ולא הוכחת התאמה לרובוט. יש לתעד מיקום, כמות, מסה, אספקת מתח ותוואי כבלים לפי [תוכנית השילוב](../skin_integration.md) לפני הוספה לרשימת החומרים של הרובוט.
