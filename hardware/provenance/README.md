# מקור, מלאי ועקיבות של חבילת החומרה

מקור: [RoboParty rp1_hardware](https://github.com/Roboparty/rp1_hardware), גרסת Git נעולה `18ca38832cde37a8a4349cff8fbb565f05c6f254`. ההפניה נשמרת לצורך ייחוס ועקיבות של תכנונים נגזרים; אין במאגר תת־מאגר או תלות ב־Git של המקור.

| מסמך | תפקיד |
| --- | --- |

| [מפת קובצי המקור](file_manifest.json) | כל 550 נתיבי המקור, נתיבי העבודה וחתימות המקור; חתימת הייצוא הראשונית אינה חתימת התוצר לאחר תרגום |
| [מפת נתיבים](path_map.json) | התאמה חד־חד־ערכית בין שמות המקור לשמות העבודה |

שמות מקור סיניים ברשומות JSON מקודדים לצורך עקיבות. הם אינם תחליף לתרגום שמות העבודה והמסמכים.

ספירת תיקיות הייצור: CNC — 303 קבצים; הדפסה תלת־ממדית — 78; גומי — 20. כל אלה כלולים בעץ העבודה. המקור כולל גם מסמכים, לוחות, צמות ורשימות חומרים.

[נכסי השחרור המקוריים](https://github.com/Roboparty/rp1_hardware/releases/tag/v0.1.0), ובהם ארכיוני SolidWorks ו־Parasolid, נפרדים מעץ Git בן 550 הקבצים. אין להציגם כמיובאים או כמותאמים בגרסה זו.

תחולת הרישיונות מפורטת ב[מסמך הרישוי](../LICENSES.md). המקור מתיר התאמות בכפוף לתנאיו; הייחוס אינו הופך את RoboParty לשותף, נותן חסות או מאשר של ROBOSKIN.

מרשם החלקים כולל שלושה כינויים המחייבים בירור מפרט לפני רכש: `ROBOSKIN.0369`, `ROBOSKIN.0370` ו־`ROBOSKIN.0371`. האחרון ממפה מזהה מכני חלקי במקור; הקצאת מספר חדש אינה פותרת את עמימות המקור ואינה מאשרת ייצור.

לבדיקת המלאי הסופי מתוך שורש המאגר:

<div dir="ltr">

```bash
python3 tools/verify_hardware_inventory.py
```

## שחזור בדיקות וכלי עריכה

בדיקות המאגר והמלאי משתמשות בספרייה התקנית של Python בלבד. כלי רינדור ה־PDF והטבלאות נבדקו בסביבת `PyMuPDF 1.28.2` ו־`Pillow 12.3.0`, עם הגופנים `NotoSansHebrew-Regular.ttf` ו־`DejaVuSans.ttf` בנתיבי Linux המפורטים בסקריפטים. שמות הגופנים וחתימותיהם מתועדות בדוחות הרינדור הרלוונטיים.

[כלי לוקליזציית STEP](../../tools/localize_step_labels.py) ו[כלי בניית טבלאות העכבה](../../tools/rebuild_impedance_tables.py) מקבלים `--source` שמצביע לעותק המקור שלא שונה. ללא `--apply` הם אינם מחליפים את קובצי ה־STEP או את חברי הארכיון; כלי הטבלאות עדיין יוצר תוצרי רינדור לבדיקה. שינוי מאושר מחייב לאחריו עדכון מפורש של מלאי המסירה באמצעות `--write`.

כלי תיקון ה־PDF משחזרים שלבי תיקון מתועדים ואינם ממיר CAD כללי. תוכניות התיקון מזהות גרסאות מקור וביניים וכוללות קואורדינטות גליפים; יש להשתמש בעותק עבודה ובתיקיית גיבוי המתאימים לשלב המתועד. דוחות כל שלב עשויים להכיל חתימות ביניים; `delivery_inventory.json` הוא המקור הקובע לחתימות הקבצים שנמסרו.
