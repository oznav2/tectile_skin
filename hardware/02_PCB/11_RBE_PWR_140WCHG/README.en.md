| Designator | Assembly status | Quantity per board |

The main sheets in the [component list](01_BOM_140WCHG_2026-09-09.xlsx) and [CPL file](04_CPL_140WCHG_2026-09-16.xlsx) contain 164 component designators to populate.

The 47kΩ resistor, manufacturer part number FRC0603F4702TS, is populated at R17,R30, with a quantity of 2 per board. NC_List retains R59 with quantity 0; it must not be included in purchasing quantities.

In BOM row 57, Unique ID preserves the original export group, which included R59. The mapping between each identifier and component designator has not been verified. For purchasing and assembly, rely on Designator and Quantity in the main sheet and on the valid CPL. When exporting the assembly BOM, use only the main sheet, excluding NC_List.
