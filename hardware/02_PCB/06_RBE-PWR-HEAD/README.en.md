The main sheet in the [component list](01_BOM_HEAD_2026-09-09.xlsx) specifies components to populate. The main sheet in the [CPL file](04_CPL_HEAD_2026-09-16.xlsx) specifies valid placement coordinates. Each contains 200 component designators to populate.

The CPL's NC_List sheet retains C30's model, package and original coordinates for traceability only. When importing or exporting placement coordinates, use only the main sheet, excluding NC_List.
