# ROBOSKIN - עור אלקטרוני

[English](README.md) · [התכנית ההנדסית המפורטת](electronic_skin.md)

זהו פרויקט עצמאי לעור אלקטרוני: איתור מגע, עוצמת מגע יחסית ומדידת טמפרטורה בנקודות מקומיות. המבנה כולל שכבת הגנה הניתנת להחלפה, יריעת חישה, בקר מקומי ותקשורת CAN FD מחולקת לאזורים.

בפאנל הייחוס 28 אתרי מגע ושתי נקודות טמפרטורה. דוגמה קומפקטית משתמשת בשמונה בקרים עם 88 אתרי מגע פעילים ו־16 נקודות טמפרטורה. המידות הן דוגמאות כלליות; התאמה פיזית לרובוט מסוים מחייבת מדידה ובדיקה.

להרצת ההדגמה והבדיקות, ללא חיבור חומרה:

```bash
python3 -m unittest discover -s tests -v
python3 -m software --demo
```

ההדגמה מציגה מידע תקין ולאחר מכן פקיעת תוקף. היא אינה מפעילה מנועים. מדידה חסרה או ישנה מסומנת במפורש ואינה הופכת לערך לחץ אפס שנראה תקין.

אומדן הייצור הוא $34.78 לפאנל תקין, בהנחות אצווה של 1,000 פאנלים. זו אינה הצעת מחיר לרכישה קמעונאית. מודל מערכת של 80 פאנלים עם מתאמי מעבדה מבודדים עומד על $7,852.40 לפני חלפים, מסים, משלוח ועבודת הנדסה. יש לקרוא את הנחות העלות לפני שימוש באומדן.

למאגר היסטוריית Git חדשה ועצמאית. אין בו תתי־מאגרים, תלות בערכת פיתוח של רובוט או קובצי CAD וייצור של רובוט חיצוני. שמות הקבצים באנגלית והתיעוד העברי כאן אינו כולל טקסט סיני.

זהו מפרט הנדסי ותוכנת מחשב שנבדקה באופן סינתטי. ייצור כרטיסים, קושחת בקר, כיול פיזי, עמידות והתאמה למפרקים עדיין דורשים בנייה ובדיקות. אין לייחס לבדיקות התוכנה הוכחת בטיחות או מוכנות לייצור סדרתי.
